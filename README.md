# LaTeX to XML Converter

This project converts LaTeX mathematical equations into XML format.  
It helps users transform LaTeX expressions into structured XML data easily.

## Features
- Convert LaTeX equations to XML
- Simple and user-friendly interface
- Fast conversion process
- Error handling for invalid input

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in browser

## Project Structure
- `index.html` → Main webpage
- `style.css` → Styling file
- `script.js` → Conversion logic
